## Objectives Completed

### Data Source: Redfin → Realtor.com
- Confirmed Redfin endpoint had thin rural coverage (0 results Kentucky, 5 Nebraska)
- Pivoted to Realtor.com via RealtyAPI — 1,969+ results per state nationwide
- Confirmed live via MCP: `searchResults[]` key, description at `detail.details.text`
- Rewrote `fetch_listings()`, `fetch_search_results()`, `fetch_listing_details()`, `normalize_listing()`, `extract_description()`, `extract_year_built()` for Realtor.com field structure

### Pipeline Fixes
- **Content parser:** strips `**bold**`, `#`, `---` from label lines — fixes Claude markdown formatting edge case
- **Empty content guard:** skips Webflow write if HEADLINE or NARRATIVE empty — prevents blank draft items
- **Affiliate URL:** uses direct `href` from search result instead of constructed zip search URL
- **Full site publish:** `publish_site()` now called automatically after each run, hardcoded domain IDs
- **Cron:** expanded to 6 runs/day (was 3) — `0 13,17,21,1,5,9 * * *`
- **1 listing per state:** `state_published` flag ensures geographic diversity

### Scoring Model Tuning
- Condo/multi-family acreage guard: nullify acreage if ≤2 beds and <900 sqft
- Cash-only/as-is AND no floor qualifier: -2 penalty
- Audience check: max score 4 if regular person with mortgage can't buy/live here
- As-is exception: fine if historic significance, acreage, waterfront, or architectural value

### Site Changes
- Removed all test/sample listings from Webflow and Supabase
- Removed Latest Deals from nav
- "See Today's Deals" button now links to `/deal-of-the-day`
- Built Deal of the Day section on homepage (static Wheeling WV content)
- Filtered Latest Deals grid to exclude deal-of-the-day listings (`isOff`)
- Added `gallery-images` MultiImage field to CMS collection
- Fixed `#deals` anchor causing homepage URL to show `/#deals`
- Updated affiliate URLs on all existing listings to direct Realtor.com property pages

### Manual Entry Process
- Established process: RealtyAPI detail call → Cloudflare upload → Webflow CMS via MCP → Supabase insert
- First manual entry: Wheeling WV castle house ($100K, score 9, Deal of the Day)
